Artifact: Travlr Getaways

A full stack travel booking web application originally built for CS-465: Full Stack Development. The application includes both front-end and back-end functionality, with API routes, database models, views, and server-side logic organized into separate folders. Routes and middleware connect components and support user interactions.

This single artifact is enhanced across all three required categories: software design and engineering, algorithms and data structures, and databases.

Project Structure

travlr-getaways/
├── app.js                          // Express root: routes, CORS, Passport init
├── app_api/
│   ├── config/
│   │   └── passport.js             // LocalStrategy with email + PBKDF2
│   ├── controllers/
│   │   ├── authentication.js       // register + login controllers
│   │   └── trips.js                // CRUD controllers for trips
│   ├── models/
│   │   ├── db.js                   // MongoDB connection
│   │   ├── travlr.js               // Mongoose trip schema
│   │   └── user.js                 // User schema: PBKDF2 hash + JWT generation
│   └── routes/
│       └── index.js                // API route definitions + auth middleware
├── app_server/
│   ├── controllers/
│   ├── routes/
│   └── views/                      // Handlebars templates (customer site)
├── app_admin/                      // Angular SPA (admin interface)
│   └── src/app/
│       ├── services/
│       │   ├── trip-data.service.ts       // API calls for trips + auth
│       │   └── authentication.service.ts  // JWT storage + login state
│       ├── add-trip/  edit-trip/  login/
│       ├── trip-card/ trip-listing/
│       └── models/    utils/
└── public/                         // Static assets (CSS, images)
